# ✅ To-Do List Web App

A simple and efficient web application to manage your daily tasks and stay organized. Add, edit, delete, and mark tasks as completed—all in one place!  

---

## 🚀 Features

- ➕ Add new tasks easily  
- ✏️ Edit existing tasks  
- 🗑️ Delete tasks you no longer need  
- ✅ Mark tasks as completed or pending  
- 💾 Saves data locally using browser storage (LocalStorage)  
- 📱 Fully responsive and easy to use on mobile or desktop  

---

## 🖥️ Tech Stack

- **HTML5** – App structure  
- **CSS3** – Styling and layout  
- **JavaScript (Vanilla JS)** – App logic and interactivity  

*(If using a backend, mention it here: Node.js, Express, MongoDB, etc.)*

---

## ⚙️ How It Works

1. Enter a task in the input field and click **Add Task**.  
2. Tasks appear in the list below.  
3. You can:  
   - Mark tasks as **completed**  
   - **Edit** a task to modify it  
   - **Delete** a task when done  
4. All tasks are stored locally so they remain after refreshing the page.
